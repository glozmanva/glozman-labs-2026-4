## Цель работы

Взаимодействие frontend-приложения с внешним API через `XMLHttpRequest`.
В ходе работы данные карточек научной аппаратуры загружаются не из `mock`, а с backend-сервера ЛР4.

## Тема

Оптимизация состава научной аппаратуры космического спутника.

## Сайт для вдохновения

[OSCAR Space](https://www.oscar-space.com/)

## Дополнительные задания

Добавлена страница добавления/редактирования карточки.
В ЛР5 на странице есть поля ввода, но сохранение не выполняется, так как кнопка сохранения появляется в ЛР6.

## План

1. Создать слой `modules` для работы с API.
2. Вынести адреса запросов в `stockUrls.js`.
3. Реализовать XHR-запросы в `ajax.js`.
4. Подключить API на главной странице.
5. Подключить API на странице подробной карточки.
6. Добавить страницу добавления/редактирования.
7. Проверить запросы во вкладке `Network -> Fetch/XHR`.
8. Показать проблему CORS и обход через `CORS Unblock`.

## Задание

Продолжение ЛР3: добавить страницу добавления/редактирования и соответствующие кнопки, подключить созданный API backend.
Запросы выполняются через `XMLHttpRequest`.
CORS обходится через расширение `CORS Unblock`.
Код ЛР4 в ветку ЛР5 не добавляется: backend запускается отдельно.
