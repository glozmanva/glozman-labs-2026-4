## Цель работы

Продолжение лабораторной работы 3: подключить фронтенд к API, созданному в лабораторной работе 4, и выполнить получение данных через AJAX-запросы на основе `XMLHttpRequest`.

## Тема

Оптимизация состава научной аппаратуры космического спутника.

В качестве карточек используются приборы космического спутника: камера, спектрометр, радиометр.

## Сайт для вдохновения

[OSCAR Space](https://space.oscar.wmo.int/instruments/view/wfv)

## Что реализовано

1. Добавлен слой `modules`:
   - `modules/ajax.js` — класс для XHR-запросов;
   - `modules/stockUrls.js` — адреса API.
2. Главная страница получает карточки с API `http://localhost:3000/stocks`.
3. Фильтрация отправляет запрос вида `http://localhost:3000/stocks?title=Камера`.
4. Страница подробной карточки получает данные по `id`.
5. Добавлена страница добавления/редактирования:
   - при добавлении поля пустые;
   - при редактировании поля заполняются данными существующей карточки;
   - кнопки «Сохранить» нет, потому что она должна появиться только в ЛР6.
6. Код бэкенда ЛР4 в этот проект не добавлен: он запускается отдельно.

## Порядок запуска

### 1. Запустить API из ЛР4

В папке проекта ЛР4:

```bash
npm run start
```

Сервер должен быть доступен по адресу:

```text
http://localhost:3000
```

### 2. Запустить фронтенд ЛР5

Открыть эту папку в VS Code и запустить `index.html` через Live Server.

Фронтенд откроется на другом порту, например:

```text
http://127.0.0.1:5500
```

## Порядок показа

1. В Google Chrome одновременно запустить:
   - сервер ЛР4 с API;
   - фронтенд ЛР5 через Live Server.
2. Открыть DevTools → вкладка `Network` → фильтр `XHR`.
3. Выполнить фильтрацию в приложении.
4. Показать ошибку CORS.
5. Включить расширение CORS Unblock.
6. Повторить фильтрацию.
7. Показать в Network запрос вида:

```text
GET http://localhost:3000/stocks?title=Камера
```

8. В Postman добавить новую запись через `POST /stocks`.
9. Обновить приложение и показать, что новая карточка появилась.
10. Указать название новой записи в фильтрации и показать результат.

## Контрольные вопросы

### Что такое AJAX?

AJAX — это подход, при котором страница обменивается данными с сервером без полной перезагрузки. Пользователь остается на той же странице, а нужные данные подгружаются сетевым запросом.

### Что такое XHR?

`XMLHttpRequest` — это объект браузера для отправки HTTP-запросов из JavaScript. В этой лабораторной через XHR выполняются GET-запросы к API, а полученные JSON-данные отрисовываются в интерфейсе.

### Что такое CORS?

CORS — это механизм безопасности браузера. Он ограничивает запросы с одного источника на другой источник, если сервер явно не разрешил такой доступ.

В этой лабораторной фронтенд и API запускаются на разных портах, поэтому для браузера это разные источники. Из-за этого запрос может быть заблокирован CORS.

### Как решить проблему CORS?

Основные способы:

1. Разместить фронтенд и бэкенд на одном домене и порту.
2. Настроить CORS-заголовки на сервере.
3. Для разработки использовать расширение CORS Unblock.

В лабораторной используется третий способ, потому что по заданию нужно показать ошибку, включить CORS Unblock и повторить запрос.
